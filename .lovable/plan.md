# План: сайт Клуба «Трансформация» — Сергей Табачников

Строим поэтапно: сначала основа (дизайн-токены, шрифты, тексты, общие элементы, подвал, юридические страницы), затем по одному разделу главной страницы, каждый — после Вашего одобрения.

## 1. Разделы главной страницы (компьютер / телефон 360px)

Каждый раздел — скруглённый «остров» (радиус 32px на компьютере, 24px на телефоне) на тёплом фоне #FBF7F1, поля 16px на телефоне, ширина контента до 1200px. Под каждым заголовком — подпись-разделитель ──◆──. Заголовки строим так: обычное слово + слово-акцент курсивом.

1. **Первый экран (Hero)**
   - Компьютер: две колонки. Слева: надзаголовок «Трансформационный клуб» (мелкие заглавные буквы с разрядкой), H1 «Клуб *Трансформация*», под ним «СЕРГЕЙ ТАБАЧНИКОВ» заглавными с разрядкой, «Проводник • Энергопрактик» и курсивная подпись «Путь к Силе Души». Подзаголовок, строка фактов (3 пункта с маленькими золотыми ромбами), основная кнопка «Вступить в Клуб», второстепенная кнопка-контур «Сначала — бесплатная диагностика, 2 минуты», мелкая ссылка «Нет Telegram? Напишите во ВКонтакте». Справа: фото-вырезка Сергея на «стене» #F3ECE2 с мягкой тенью оливковой ветви (тень — отдельный полупрозрачный слой, который можно двигать, без генерации людей).
   - Телефон: сначала фото (обрезано по грудь, ~55% высоты экрана), сразу под ним имя и подпись, затем H1, факты столбцом, кнопки на всю ширину. Сергей виден без прокрутки.
   - Сверху — минимальная шапка: имя-логотип и одна кнопка Telegram; на телефоне без бургер-меню.
2. **«Этот клуб для Вас, если…»** — 5 карточек с номерами 01–05 (номер крупно, светлым серифным шрифтом). Компьютер: сетка 3+2; телефон: столбец. Внизу — маленький круглый портрет Сергея с короткой фразой от первого лица, чтобы его присутствие ощущалось.
3. **«Почему действия не меняют сценарий»** — на компьютере две колонки: слева тезис, справа схема из трёх шагов (Внутреннее напряжение → Программа → Повторяющийся результат) тонкими линиями с золотыми ромбами. Внизу — цитата Сергея с его подписью. Остров светло-шалфейного цвета #E3EBE6.
4. **«Ведущий клуба»** — фото Сергея + путь в виде временной шкалы (27 лет в бизнесе → кризис пустоты → поиск → метод). Круглое приветственное видео (кнопка воспроизведения, звук включается по нажатию, превью-постер, загрузка только при нажатии). Строка из 3–4 цифр его практики. Телефон: видео → шкала → цифры сеткой 2×2.
5. **«Что даст Вам клуб»** — 4 карточки сфер (Здоровье, Финансы, Отношения, Предназначение) с тонкими линейными значками; для каждой — «было → становится» в 2–3 строки. Компьютер 4 в ряд / 2×2, телефон столбцом.
6. **«Как устроен месяц в клубе»** — карточки формата с метками частоты: Живая встреча (Раз в неделю), Канал группы и сопровождение (Каждый день), Медитации (Бонус), Архив +2 недели (После потока). Метки — таблетки цвета #A9BFB3 с тёмным текстом.
7. **Отзывы** — горизонтальная лента круглых видеоотзывов (прокрутка свайпом на телефоне, стрелки на компьютере) + 3–6 текстовых цитат с именем, возрастом и родом занятий (только реальные, с согласия людей).
8. **Стоимость** — одна центральная карточка: «9 990 ₽» крупно, «или 100 € — для зарубежных карт», «Разовый платёж · без автосписаний», список того, что входит (галочки в виде ромбов), кнопка «Вступить в Клуб», «Нет Telegram?» → ВКонтакте. Без зачёркнутых цен и таймеров.
9. **«Не готовы сразу? Начните бесплатно»** — 4 шага-лесенка: Тест 2 мин → Аудиопрактика → Сканирование 30 мин в Zoom (с пометкой «после теста») → Открытые встречи раз в месяц. Компьютер: горизонтальная линия с ромбами-шагами; телефон: вертикальная. У каждого шага своя ссылка.
10. **Вопросы и ответы (FAQ)** — раскрывающийся список (доступен с клавиатуры), 8–10 вопросов, включая «Это медицинская помощь?», «Что если я пропущу встречу?», «Как оплатить из-за рубежа?».
11. **Финальный призыв** — портрет Сергея, короткое личное обращение, обе кнопки, ссылка на ВКонтакте.

**Подвал:** реквизиты ИП, ссылки на /privacy, /consent, /offer, заметное предупреждение «Практики не являются медицинской или психотерапевтической помощью…», значки Telegram / ВКонтакте / YouTube.

**Другие страницы:** /privacy, /consent, /offer — спокойная текстовая вёрстка на одном «острове» с оглавлением; страница 404 в том же стиле с кнопкой «На главную». У каждой страницы — свой заголовок и описание для поисковиков и соцсетей.

## 2. Структура (технические детали)

```text
src/content/
  site.ts        имя, роли, подпись, реквизиты, предупреждение
  links.ts       ВСЕ внешние ссылки (бот, личные сообщения, ВК, YouTube, тест, аудио, Zoom)
  hero.ts  pains.ts  rootCause.ts  host.ts  areas.ts
  format.ts  reviews.ts  pricing.ts  freeLadder.ts  faq.ts  finalCta.ts
  legal/privacy.ts  consent.ts  offer.ts
src/components/
  layout/   SiteHeader, SiteFooter, Island (обёртка раздела), Container
  ui-brand/ SectionTitle (заголовок + курсивный акцент + разделитель), DiamondDivider,
            CtaButton (внешняя ссылка, target=_blank, rel=noopener), TelegramFallback,
            CircleVideo (лениво подгружаемое видео), NumberedCard, FrequencyBadge, Signature
  sections/ Hero, Pains, RootCause, Host, Areas, Format, Reviews, Pricing,
            FreeLadder, Faq, FinalCta
src/routes/  index.tsx, privacy.tsx, consent.tsx, offer.tsx (404 — в __root)
```

- В компонентах нет текста: всё берётся из src/content/*.ts (типизировано).
- Ссылки — только в links.ts; у каждого призыва — data-атрибут для будущей аналитики.
- Без базы данных, форм и оплаты. Шрифты подключаются в head, только кириллица + латиница, font-display: swap.
- Изображения: AVIF/WebP с srcset; видео загружаются только по нажатию.
- Тест на то, что в pricing.ts указаны 9 990 ₽ / 100 € и пометка «без автосписаний», и что у каждого призыва есть ссылка.

Шрифты: --font-display Cormorant Garamond (500/600, курсив 500), --font-body Manrope (400/500/600). Шкала размеров через clamp(): H1 40→72px, H2 32→52px, основной текст 17–18px, межстрочный 1.6. Отдельный класс для имени: заглавные буквы, разрядка 0.18em. Тёмную тему не делаем (исключим по согласованию).

## 4. Материалы от Вас

1. **Фото для первого экрана** — PNG с прозрачным фоном, ≥2000px по высоте, по пояс или по грудь, взгляд в камеру или чуть в сторону. Если вырезки нет — пришлите исходник, я удалю фон.
2. **Портрет для раздела «Ведущий»** — JPG, ≥1600px, вертикальный 4:5.
3. **2–3 дополнительных фото** (в работе, на встрече, крупный план) — JPG, ≥1200px.
4. **Тень оливковой ветви** — если есть фото стены с тенью (≥2400px); иначе я подготовлю нейтральную текстуру тени без людей.
5. **Приветственное видео** — MP4 (H.264), квадрат 1:1, 720–1080px, до 60–90 сек, до ~15 МБ + кадр для превью.
6. **Видеоотзывы** — те же требования, у каждого: имя, возраст/род занятий, письменное согласие на публикацию.
7. **Текстовые отзывы** — 3–6 штук с именем и подписью.
8. **Цифры практики** — например, годы, число людей, встреч (только проверяемые).
9. **Реквизиты ИП** — ФИО, ИНН, ОГРНИП, email для связи.
10. **Тексты политики, согласия и оферты** — или разрешение на шаблонные тексты, которые затем проверит юрист.
11. **Все ссылки**: Telegram-бот, личный Telegram, ВКонтакте, YouTube, тест, аудиопрактика, запись на Сканирование, открытые встречи.
12. Фавикон / монограмма — по желанию; иначе я сделаю монограмму «СТ» шрифтом Cormorant.

## 5. Вопросы перед началом работы

1. Основная кнопка «Вступить в Клуб» ведёт в бота или в личные сообщения Сергея? А бесплатная диагностика — в того же бота?
2. Тест на 2 минуты уже существует (в боте) или его тоже нужно сделать?
3. Оплату в 100 € ведёт тот же бот или отдельная ссылка/человек?
4. Есть ли даты ближайшего потока, которые можно спокойно указать (например, «Старт — 2 ноября»)? Без таймера.
5. Цифры практики Сергея — какие можно использовать?
6. Нужна ли английская версия когда-либо (это повлияет на структуру текстов)?
7. Нужна ли аналитика (Яндекс Метрика) уже в первой версии? Если да — потребуется баннер о cookies.
8. Есть ли домен для сайта?
